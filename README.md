# Jolt Code

**Idea to project, from your pocket.**

Jolt Code is an iPhone app that sends the code you write straight to your ESP32, Pico W or any MicroPython Wi-Fi board. No laptop, no cable.

This repository holds the Jolt website, including the privacy policy, terms of use and support details. It does not contain the app's source code.

## What Jolt does

- **Write**: a code editor made for a phone, with one-tap shortcut keys for Python and HTML.
- **Send**: press play and your code runs on the board over Wi-Fi, with live output in a terminal.
- **Start fast**: plugins for common sensors, switches and lights, each with a wiring guide.
- **Control**: build a web page with buttons and use it as a remote for your device.
- **Fix**: browse the files on your board, edit one and send it back.
